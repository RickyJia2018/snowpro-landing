# 购买前端修复

检查范围仅限网站前端的 SnowCoin 与 Carpool Pass，配合 SnowPro Flutter 的构建分流。未修改后端，未部署或进行真实扣款。

- Token / Pass 使用不同短期会话存储，避免用途与账号交叉；App 一次性链接只从 URL fragment 读取并立即清理。
- 新 Pass 链接兑换时清除旧账号购买会话；兑换失败不回退旧身份；React StrictMode 不会重复消费一次性链接。
- 购买增加同步互斥和请求超时，重定向期间保持锁定；过期会话不能继续购买。
- 两种购买都严格检查 Stripe Hosted Checkout 地址；拒绝非 HTTPS、非精确域名、携带用户名密码的链接。
- 延迟返回的旧账号请求不能恢复已退出的用户或替新账号发起跳转。
- 不向用户显示服务器原始异常、堆栈或内部 URL；无效商品 ID、金额不会被当成免费商品展示。
- Pass 从 App 传入的套餐会被保留；原有 1/2/3/4 月与 US$0.99/1.99/2.99/3.99 数值未变。已请求用户确认上线价格，不擅自制定新套餐。
- Pass 返回页不把访问页面视为付款成功。网页没有新增或猜测后端付款确认接口，到账仍需现有服务确认。
- 移除未使用的 Gemini 密钥构建注入配置；前端购买流程不需要该密钥。

验证：34 个测试通过，TypeScript 检查及 Vite 生产构建通过。支付账号归属、Stripe 真正完成付款后的到账，以及 App 回跳需要测试环境联调；本次未声称验证生产交易。
